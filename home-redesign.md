Crie um design moderno para uma loja virtual B2B focada em catálogo de produtos e solicitação de orçamentos (RFQ). O site deve ser clean, profissional, mobile-first, com navegação intuitiva para compradores industriais. Priorize: descoberta rápida de produtos, filtros avançados, visualização detalhada de especificações técnicas, e um fluxo simplificado de 'Solicitar Orçamento'. Estética minimalista com cores sóbrias (azul escuro/cinza), tipografia legível, e elementos de confiança (certificações, cases). Inclua: busca inteligente, comparação de produtos, e área do cliente para acompanhar status de orçamentos."

Tipografia
Títulos: Inter ou Roboto (sans-serif moderna)
Corpo: 16px mínimo, line-height 1.6
Especificações técnicas: Fonte monoespaçada (Courier/Code) para SKUs e medidas
Layout
Grid: 12 colunas, gutters generosos (24px)
Cards de produto: Hover com elevação + shadow sutil
Whitespace: 40% da tela deve ser espaço vazio (não poluir)
Mobile: Menu hambúrguer com busca sempre visível (sticky top)
⚡ Funcionalidades Interativas Essenciais
Comparador de Produtos: Checkbox para selecionar até 3 itens, tabela lado a lado
Calculadora de Volume: Input de quantidade → mostra desconto progressivo
Chat/Widget de Dúvidas: Fixo no canto inferior direito
Visualização Rápida: Modal com resumo sem sair da listagem
Salvar Orçamento: Gerar PDF do carrinho para aprovação interna do cliente
🛠️ Exemplo de Fluxo de Usuário para Descrever
"O comprador acessa o site → Busca por 'válvula industrial' → Aplica filtros (pressão máxima, material) → Visualiza 12 produtos → Clica em 'Quick View' → Adiciona 3 itens à lista de comparação → Seleciona o melhor → Clica 'Solicitar Orçamento' → Preenche formulário com quantidade 500 unidades → Recebe confirmação por email → Acessa área 'Meus Orçamentos' para acompanhar."

💡 Dicas de Otimização
Segundo as melhores práticas de 2024/2025 :
Velocidade: Imagens em WebP, lazy loading, carregamento < 3 segundos
Acessibilidade: Contraste WCAG AA, navegação por teclado, alt text nas imagens
SEO: URLs amigáveis, rich snippets de produto, schema.org para preços
Conversão: Reduzir campos do formulário ao mínimo necessário, usar progress bar em multi-steps
